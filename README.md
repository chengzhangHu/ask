# 问知识库（公开入口）

这是「前端漫谈」个人技能知识库的**公开问答入口**（`huchengzhang.com`）。

- 提交问题后，会由自动化流程检索**公开已发布文章**并回帖。
- 回答仅基于公开内容；内部实现、框架方法论等内部知识**不会**在此公开。
- 采用**定时批量回复**，非即时回复，请勿重复提交相同问题。

## 常见问题

- **多久回复？** —— 提问后约 **1–2 小时**内回复（定时批量处理，非即时）。
- **为什么不是马上回？** —— 为控制负载、保证服务稳定，问题会进入队列按批次处理。
- **每天能问多少？** —— 同一账号 24 小时内最多 3 条；全站每日总量上限 30 条（超出部分可能被忽略，请次日再试）。
- **没命中怎么办？** —— 会记录为待研究选题，由维护者跟进整理。

> 本仓库是公开收纳层，不含任何运行时脚本与密钥。
